在出差电脑上连接 SSH

需要 Node.js 22 或更新版本，以及你的登录密钥。首次使用，下载 SSH 隧道工具，与密钥放在同一文件夹。

node umeko-remote.mjs --identity ./admin.umeko-key

保留该终端，在另一个终端执行：

ssh -p 2222 -o HostKeyAlias=umeko-home umeko@127.0.0.1

隧道会验证你的专属密钥；SSH 随后使用家中电脑原有的 SSH 密钥或密码。SSH 客户端可更换为 VS Code Remote SSH、SFTP 等工具。会话最长 8 小时。
