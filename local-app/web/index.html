接入说明

本地程序只负责转发，不会启动或管理推理进程

01

先启动你的推理服务

使用 llama.cpp、vLLM 或 SGLang 启动 OpenAI 兼容服务，确认本机 /v1/models 可以访问。无需公网 IP 或端口映射。

02

在云端创建供应商和 API Key

供应商凭据用于本地 CLI 连接云端；umo-sk API Key 用于外部调用。云端负责 Key 分发、计费、额度与并发限制。

03

三种入口共用同一个核心

CLI 是主要运行方式；Qt/QML 和此 Web 页面是附属管理界面。配置保存在当前用户的 QSettings 中。
