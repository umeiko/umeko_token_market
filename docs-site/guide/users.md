# 注册用户与自助门户

除了管理员登录，云端还提供 `/portal` 用户入口。用户无需密码，通过邮箱验证码注册和登录。

## 注册与登录

1. 输入常用邮箱并完成可选 Turnstile 人机验证；
2. 收到 6 位验证码后，在 10 分钟内输入；
3. 新邮箱验证成功后自动创建账户，已有邮箱直接登录；
4. 会话保存在 HttpOnly、SameSite=Strict Cookie 中，有效期 7 天。

生产环境必须配置 SMTP。开发模式可以把验证码打印到云端日志，但验证码不会通过 API 返回。

## 用户能力

- 查看当前在线模型及输入/输出价格；
- 查看五小时和七天滚动窗口的已用、剩余额度；
- 查看最近一小时的请求数、Token、成功率和最多 100 条日志；
- 自助申请最多 3 个启用的 API Key，可停用和恢复；
- 获取 Base URL、环境变量、curl 和 Python OpenAI SDK 接入示例。

用户所有 Key 默认共享账户额度。管理员也可以把某个 Key 配置标记为“允许注册用户申请”，用户随后能按该 Key 的五小时、周限额、RPM 和并发策略申请自己的新 Key。原始管理员 Key 不会共享或暴露，账户级限额仍然同时生效。

## 默认额度

| 窗口 | 默认值 | 计算方式 |
| --- | --- | --- |
| 五小时 | 2,000,000 Token | 最近五小时滚动汇总 |
| 周 | 20,000,000 Token | 最近七天滚动汇总 |

额度检查发生在每次公开 API 请求前，日志在响应结束后写入。任一窗口达到上限后返回 `429`。

## 管理员用户管理

“注册用户”页面支持：

- 按邮箱前缀或用户 ID 进行 SQL 索引搜索，180ms 防抖，最多返回 50 条；
- 修改每个用户的五小时和周额度，`0` 表示不限；
- 停用或恢复账户。停用后登录失效，其所有 Key 返回 `401`；
- 单独重置五小时额度，或同时重置五小时和周额度。

重置通过更新额度起算时间实现，不删除历史日志。历史账单仍完整保留，但对应窗口的已用额度从新起点重新汇总。

## 防批量注册与验证码滥用

服务端同时执行以下限制，前端显示不是安全边界：

- 每个 IP 每小时最多请求 10 次、每天最多 30 次验证码；
- 每个邮箱每天最多 5 次验证码，且两次发送至少间隔 60 秒；
- 每个 IP 每天最多注册 5 个新账户；
- 验证码 10 分钟过期、最多尝试 5 次，新验证码使旧验证码失效；
- 验证码使用 scrypt 哈希存储，不保存明文；
- 常见一次性邮箱域名拦截，可用 `BLOCK_DISPOSABLE_EMAIL=false` 关闭；
- 隐藏表单蜜罐；
- 可配置 Cloudflare Turnstile，配置后服务端强制校验 token；
- IP 来自 Fastify，只有可信反向代理后才启用 `TRUST_PROXY=true`。

这些措施用于提高自动化攻击成本，不替代邮件服务商限流、WAF、账户审计和云端总请求限制。
