# 云端管理

管理面板和公开 API 共用云端端口。登录后，左侧导航分为运行概览、供应商与模型、API Key、用量与账单、请求日志和系统设置。

## 运行概览

概览展示：

- 今日请求、Token、费用与成功率；
- 在线供应商和活跃 API Key 数；
- 最近 14 天请求与 Token 趋势；
- 最新请求及其模型、Key、供应商、延迟和状态。

## 供应商与模型

供应商代表一个通过反向隧道接入的本地节点。创建供应商时会生成 `umo-agent-...` 连接凭据。

### 状态区别

| 状态 | 含义 |
| --- | --- |
| 在线 | WebSocket 已鉴权，本地 `/v1/models` 健康检查成功 |
| 推理异常 | 本地连接器在线，但推理地址不可达或返回非 2xx |
| 离线 | 没有可用的已鉴权 WebSocket，或供应商被停用 |

只有“在线”的供应商会出现在 `/v1/models` 并参与请求选择。

### 模型与价格

模型名称是调用方使用的对外标识。多个供应商可配置相同模型，云端按当前活动请求数选择可用节点。输入和输出价格分别按每百万 Token 的美元金额配置。

### 凭据轮换

“重置连接凭据”会立即断开旧本地连接。使用新凭据执行 `utoken up` 后恢复。旧凭据不会保留可恢复的明文。

## API Key

每个 Key 独立保存用量和限制：

- Token 总额度；
- 费用额度；
- 每分钟请求数（RPM）；
- 最大并发；
- 过期时间；
- 启用或停发状态。

额度为 `0` 表示不限制，过期时间为空表示永久有效。编辑时可以选择将累计用量和费用清零。

## 用量与账单

账单页按 Key 汇总 Token 与费用。这里记录的是中转站运营计费，不包含在线支付、发票或自动扣款功能。

## 请求日志

可以按 Key、供应商和成功/失败状态筛选。日志包含请求 ID、模型、输入/输出 Token、费用、延迟、HTTP 状态和错误信息，不保存提示词与模型输出正文。

## 系统设置

- 修改控制台服务名称；
- 调整本地推理请求超时，范围 5 秒到 30 分钟；
- 修改管理员密码，新密码至少 10 个字符。
