# 云端管理

管理面板和公开 API 共用云端端口。登录后，左侧导航分为运行概览、供应商与模型、API Key、用量与账单、请求日志和系统设置。

## 运行概览

概览展示：

- 今日请求、Token、费用与成功率；
- 在线供应商和活跃 API Key 数；
- 最近 14 天请求与 Token 趋势；
- 最新请求及其模型、Key、供应商、延迟和状态。

## 供应商与模型

供应商代表一个通过反向隧道接入的本地节点。创建供应商时会生成 `umo-agent-...` 连接凭据。

### 状态区别

| 状态 | 含义 |
| --- | --- |
| 在线 | WebSocket 已鉴权，本地 `/v1/models` 健康检查成功 |
| 推理异常 | 本地连接器在线，但推理地址不可达或返回非 2xx |
| 离线 | 没有可用的已鉴权 WebSocket，或供应商被停用 |

只有“在线”的供应商会出现在 `/v1/models` 并参与请求选择。

### 模型与价格

模型名称是调用方使用的对外标识。多个供应商可配置相同模型，云端按当前活动请求数选择可用节点。输入和输出价格分别按每百万 Token 的美元金额配置。每个模型还可填写上下文长度（Token），例如 256K 填 `262144`，`0` 表示未声明；该值会通过 `/v1/models` 返回，便于客户端识别模型容量。

### 凭据轮换

“重置连接凭据”会立即断开旧本地连接。使用新凭据执行 `utoken up` 后恢复。旧凭据不会保留可恢复的明文。

## API Key

每个 Key 独立保存用量和限制：

- Token 总额度；
- 费用额度；
- 每分钟请求数（RPM）；
- 最大并发；
- 过期时间；
- 启用或停发状态。

额度为 `0` 表示不限制，过期时间为空表示永久有效。Key 卡片会分别显示当前 5 小时、当前一周滚动窗口的已用 Token 和限额，以及累计 Token 和费用用量。配置页提供“重置 5h 限额”“重置周限额”和“重置全部限额”：单独重置只清零对应窗口，全部重置会清零累计 Token、费用和两个窗口，历史日志、凭据与配置均保留。

五小时或周限额耗尽时返回 HTTP 429 和 `rate_limit_error`，错误中包含 ISO 8601 格式的 `reset_at`、倒计时秒数 `retry_after_seconds`、窗口标识 `quota_window` 和中文恢复时间，同时返回 `Retry-After` 响应头。恢复时间按滚动窗口内的实际 Token 记录计算，即最早能让窗口用量降回限额以下的时刻。

每个 Key 的“接入信息”入口集中显示 Base URL、Model ID、Key 和可复制的环境变量。卡片只保留接入信息、配置、克隆和日志入口；生成新 Key、停发/恢复和永久删除统一位于配置页的“凭据与状态操作”区域。轮换确认后旧 Key 立即失效，新 Key 和接入环境变量自动复制，原额度、用量、模型权限和客户端规则保持不变。

“克隆”会新建一条独立 Key，继承额度、模型权限、客户端规则和过期时间，但不继承原 Key 的凭据和用量。“日志”按钮会跳转到请求日志并自动按当前 Key 筛选，也可在日志页手动切换 Key。“删除”需二次确认，删除后凭据立即失效且不可恢复，历史日志和统计数据保留并显示为“已删除 Key”。

“可用模型”支持白名单：不勾选表示全部模型，勾选后仅允许指定模型。白名单同时作用于 `/v1/models` 和实际调用，接入信息弹窗也只列出该 Key 可选择的 Model ID。

User-Agent 过滤规则按 Key 配置。管理员可在 Key 配置中填写“客户端不匹配时的流式提示”，不匹配时以 OpenAI 或 Anthropic SSE 返回该自定义文字，并在请求日志中分类为“客户端拦截”。提示支持 `{{userAgent}}` 占位符，最多 2000 字。现有 Key 默认保留“请使用umeko-desktop来提问吧”，供应商不再保存客户端过滤规则。

管理员打开“接入信息”时，可通过专用 reveal 接口解密查看已有 Key，不需要重新生成。Key 使用 AES-256-GCM 加密存储，只有管理员会话可读取；早期仅保存哈希的旧 Key 无法恢复，需要替换一次后才能查看。

## 用量与账单

账单页按 Key 汇总 Token 与费用。这里记录的是中转站运营计费，不包含在线支付、发票或自动扣款功能。

## 请求日志

请求与拦截统一显示在同一页面，不再使用独立的拦截记录页面。可以按 Key、供应商、分类和 HTTP 状态筛选。列表直接显示 IP、地区和用户客户端；每条请求都可展开查看请求 ID、模型、Token、具体错误原因、IP、IP 地区、User-Agent 和请求头，不保存提示词与模型输出正文。

公网 IP 归属地异步查询国家、省/州和城市，不阻塞模型请求，成功结果缓存 24 小时，相同 IP 的并发查询会合并。内网和回环地址分别标记为“内网地址”和“本地地址”，不会发送到外部查询服务。默认查询服务为 `ipwho.is`，可通过 `IP_GEO_LOOKUP_URL` 替换。

分类包括正常、客户端拦截、限流、Key 错误、请求格式错误、供应商离线、上游鉴权错误和上游错误。上游返回的错误消息会显示在详情中，便于区分供应商 Key 失效和其他上游故障。

页面最多展示最近 300 条请求，所有可见日志都完整保留 IP、IP 地区、User-Agent、错误原因和脱敏请求头，不再按 5 小时清除详情。最近 150 条始终位于保留范围内。超出 300 条的旧日志从管理员和用户页面移除，其 IP、地区、请求头和错误详情同时清除，仅保留 Token、费用、状态和时间等统计字段，避免影响计费与限额。`Authorization`、`x-api-key` 和 `Cookie` 入库前始终脱敏。

## 系统设置

- 修改控制台服务名称；
- 调整本地推理请求超时，范围 5 秒到 30 分钟；超时覆盖响应头和流式正文，客户端取消、上游异常断流或超时都会取消上游并释放并发名额；
- 修改管理员密码，新密码至少 10 个字符。
